# .known-dead-links.txt — the PINNED BASELINE for regress/check_wiki_links.sh
#
# Same shape, same reason, and the same both-directions enforcement as the two
# baselines that already exist (wiki/.known-rule-violations.txt for the five
# SCHEMA page rules, wiki/.known-stale-diagrams.txt for renders):
#
#     <file> <link> <reason...>
#
#   a dead link NOT listed here          -> NEW        -> red
#   a listed link that no longer dies   -> STALE-LINK -> red
#
# The second direction is the one that makes a pin safe to write. Without it a
# pin outlives its defect: somebody fixes the link, the line stays, and the gate
# keeps reporting a dead link it can no longer see, so the log and the tree
# disagree with nothing to say which is true. When a link is fixed this gate turns
# red and names the line to delete. A pin is a receipt, not an excuse.
#
# STATUS 2026-09-26: NO PINS REMAIN. Measured on the MERGED tree, not on a branch:
# 72 documents in scope (wiki/** minus wiki/raw/, plus README.md and docs/*.md),
# 708 links checked, 0 dead.
#
# FOUR CLASSES were found while building this and all four were ruled NOT dead.
# Each ruling is recorded in the checker's header, because ruling a link "not
# dead" is as much a judgement as calling it dead, and the gate's value depends
# entirely on those judgements being deliberate:
#
#   1. reviews/ and logs/ are OUT OF SCOPE. A reviews/ record is evidence, and a
#      path inside it that pointed at ../../rtl/pe_line_codec.v was TRUE WHEN
#      WRITTEN. Rewriting it to follow a rename would falsify the evidence, and
#      flagging it would cry wolf forever, because a review is a snapshot and
#      snapshots do not age. Same for rotated logs/. What must never 404 is the
#      prose a reader is reading now.
#   2. `sources:` frontmatter is a CITATION, not an outbound link, so frontmatter
#      is stripped: BODY ONLY. A reviews/...md citation is relative to the repo
#      root, not to the page, so scanning it manufactures false dead links.
#   3. A LEADING `/` is SITE-ABSOLUTE. The one real candidate,
#      /protocol-emulator-asic-competition/oscilloscope-clean.png in
#      wiki/raw/, is a web path from the captured article, not a file here.
#   4. A wikilink inside inline code or a fenced block is a worked EXAMPLE of
#      the syntax, not a link — SCHEMA.md says "Use `[[wikilinks]]` to link
#      between pages", and the backticks are what make it an example.
#
# A note on the count that was wrong twice: an earlier measurement reported 38
# dead links, 37 of them the README diagram gallery. They were real, but
# diag-bus had already repaired them on main and the branch was behind. The same
# error was then made a second time by a first draft of this checker, whose
# "find everything" scope swept in 67 reviews/ records and 1 rotated log archive
# and reported 194 dead links — every one of them invented. A gate that cries
# wolf gets switched off, which protects nothing, so that draft was reverted
# rather than shipped. The number recorded above is the one the shipped checker
# measures on the merged tree.
#
# TO PIN SOMETHING: fix the link first, then add the line. A pin is a record that
# a rule is currently not met, and the whole value of this file is that every
# line in it is true.
