Run strap

One hardware breakpoint, PC-only. A hit stops before the instruction at that address, so you can inspect it and then step that very instruction. Clear & release is the only way off a held core: with the run strap high the core resumes, otherwise it falls to the boot stop (PC 0) — and it disarms the breakpoint, so Continue (keep bp) steps off, clears, then re-arms. Contract: chip repo R3-DEBUG-CONTROL-CONTRACT.md; the host's vectors are not yet chip-confirmed.
